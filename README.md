# Econometría Interactiva

Versión robusta para Streamlit Community Cloud.

## Archivos necesarios en la raíz del repositorio

```text
app.py
requirements.txt
.streamlit/
    config.toml
README.md
```

No utiliza `st.Page`, carpetas `views/` ni archivos de datos externos.

## Despliegue

En Streamlit Community Cloud selecciona:

- Repository: tu repositorio de GitHub
- Branch: `main`
- Main file path: `app.py`

Después pulsa **Deploy** o **Reboot app** si ya estaba desplegada.
